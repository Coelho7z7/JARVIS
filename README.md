
O JARVIS foi criado como um projeto de automação e exploração de recursos de reconhecimento de voz, execução de comandos e interação com o sistema operacional.

Funcionalidades
Controle do computador por comandos de voz
Abertura e fechamento de aplicativos
Execução de comandos
Automação de tarefas
Interação com funções do sistema
Respostas por voz
Execução de ações através de comandos
Registro de atividades em arquivo de log
Tecnologias
Python

Automação do sistema
Processamento de comandos

Como executar

Clone o repositório:

git clone https://github.com/Coelho7z7/JARVIS.git

Entre na pasta:

cd JARVIS

Execute o projeto:

python jarvis_v3.py
Como funciona

O JARVIS recebe comandos do usuário, interpreta a solicitação e executa a ação correspondente no computador.

O projeto utiliza interação por voz para tornar o controle mais natural, permitindo que tarefas sejam executadas sem a necessidade de realizar todas as ações manualmente.

Objetivo

Este projeto foi desenvolvido como uma experiência prática em Python, automação e desenvolvimento de assistentes pessoais.

A ideia é continuar evoluindo o JARVIS com novas funcionalidades, comandos e integrações.
